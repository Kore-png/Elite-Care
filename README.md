# موقع الرعاية النخبوية

## الملفات
- `index.html` — الموقع الرئيسي
- `admin.html` — لوحة تحكم للأخصائيين (محمية بكلمة مرور)
- `data.json` — بيانات الأخصائيين والخدمات والأسعار والألوان
- `images/` — صور الأخصائيين الثلاثة

## كيفية رفع الموقع على GitHub Pages (مجانًا)

1. اذهب إلى https://github.com وسجّل حساب لو مالكش واحد.
2. اضغط **New repository** واختار اسم زي `elite-care-site`، خليه **Public**، ثم **Create repository**.
3. في صفحة الريبو الجديد، اضغط **uploading an existing file**.
4. اسحب كل الملفات دي مع بعض (بما فيهم مجلد `images` كامل):
   - `index.html`
   - `admin.html`
   - `data.json`
   - `images/kareem-gomaa.jpg`
   - `images/sayed-abdelfadil.jpg`
   - `images/fares-mohamed.jpg`
5. اضغط **Commit changes**.
6. روح لـ **Settings** (في الريبو) → **Pages** من القائمة الجانبية.
7. تحت **Branch** اختار `main` والمجلد `/ (root)`، ثم **Save**.
8. استنى دقيقة أو اتنين، هيظهرلك رابط الموقع فوق بالشكل ده:
   `https://your-username.github.io/elite-care-site/`

الموقع هيبقى شغال على الرابط ده لأي حد يفتحه.

## الدخول للوحة التحكم

روح على: `https://your-username.github.io/elite-care-site/admin.html`

كلمة المرور الحالية: **EliteCare2026**

### لازم تغيّر كلمة المرور
افتح ملف `admin.html`، دور على السطر ده تقريبًا في أول الكود:
```js
const ADMIN_PASSWORD = 'EliteCare2026';
```
غيّر `EliteCare2026` لكلمة مرور خاصة بيكم، واحفظ، وارفع الملف تاني على GitHub.

## ملاحظة مهمة جدًا عن طريقة حفظ التعديلات

لوحة التحكم دي بتحفظ التعديلات (الأسعار، الصور، الألوان) على **نفس الجهاز والمتصفح** اللي عملتوا منه الحفظ، مش على السيرفر. يعني:

- لو أنت فتحت لوحة التحكم من موبايلك وعدّلت سعر، التعديل ده هيظهر بس على موبايلك أنت.
- لو حد تاني فتح الموقع من جهاز مختلف، هيشوف البيانات الأساسية اللي في `data.json` مش التعديل بتاعك.

**السبب:** الموقع "ثابت" (Static) على GitHub Pages، يعني مفيهوش قاعدة بيانات حقيقية شغالة بتستقبل وتخزن تعديلات من كل الأجهزة.

### لو عايزين التعديلات تظهر لكل الناس فورًا
فيه طريقتين:
1. **الطريقة البسيطة:** لما تعدّلوا حاجة في لوحة التحكم، انسخوا نفس التعديل يدويًا في ملف `data.json` وارفعوه تاني على GitHub. ده بياخد دقيقة والتعديل يبقى ظاهر للجميع.
2. **الطريقة الاحترافية:** لو عايزين التعديل يتحفظ تلقائيًا لكل الزوار من غير ما ترفعوا حاجة يدوي، محتاجين نضيف قاعدة بيانات حقيقية (زي Firebase أو Supabase) بدل الاعتماد على المتصفح، وده تطوير إضافي ممكن نعمله لو حبيتوا.

قولولي لو عايزين الخطوة التانية (قاعدة بيانات حقيقية) وهعملها.
